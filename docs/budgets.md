# 성능 예산 (원본)

## 데스크톱 편집

| 항목 | 값 |
|---|---|
| 기준 기기 | 저사양 PC·노트북 내장 그래픽, 30fps |
| 방 에셋 상한 | 200개 (상한 근접 시 챗봇이 안내) |
| 생성 에셋 1개 | 약 5천 삼각형으로 자동 감량, GLB |
| 방 전체 | 최대 약 100만 삼각형 (200개 × 5천) |
| 텍스처 | 1024, KTX2 압축 (생성 원본 4096은 보관만) |

내장 그래픽은 VRAM을 시스템 메모리와 나눠 쓴다. 병목은 삼각형보다 텍스처 메모리다: 2048 비압축이면 에셋당 약 21MB(밉맵 포함), 200개면 약 4GB. 1024 KTX2면 에셋당 약 1.3MB, 200개에 약 270MB.

## VR 감상 (Quest 2 기준 설계)

| 항목 | 값 | 이유 |
|---|---|---|
| 방 전체 삼각형 | 50만 이하 | Quest 2 하한 75만에서 아바타·환경 몫을 뺀 값 |
| 에셋 1개 | 약 2,500 삼각형 (VR LOD) | 200개 × 2,500 = 50만 |
| draw call | 150 이하 | 에셋마다 텍스처가 달라 아틀라스·정적 병합 필수 |
| 텍스처 | 1024, KTX2/Basis | Meta 권장 압축 포맷 |
| 아바타 | 1인 1만 삼각형 이하, 최대 5인 | - |

## 근거: Meta 공식 수치

Meta WebXR 문서는 수치를 주지 않는다. 아래는 Meta Unity(네이티브) 성능 문서 값이다. WebXR은 브라우저·WebGL 오버헤드가 있어 **범위의 하한을 상한으로** 쓴다(추정).

| 기기 | draw call (부하 큼 / 보통 / 가벼움) | 프레임당 삼각형 |
|---|---|---|
| Quest 2 | 80–200 / 200–300 / 400–600 | 75만–100만 |
| Quest 3 · 3S | 200–300 / 400–600 / 700–1000 | 130만–180만 |

프레임 예산: 72fps = 13.7ms, 90fps = 11.1ms.
