# M1 — 수업 준비와 입장

상위: [MAN-001](../PLAN.md)

**목표:** 강사 수업 개설부터 학생 입장·복귀까지 촬영

| 티켓 | 결과 | 선행 |
|---|---|---|
| [M1-01](../tickets/M1-01.md) 로그인 화면 구성 | 학생·강사 역할 탭, 학생의 '작품 만들기'·'VR 감상' 경로 표시 스샷 | M0-06 |
| [M1-02](../tickets/M1-02.md) 강사 계정 등록 | 강사 아이디·비밀번호 입력과 '강사 계정 만들기' 버튼 스샷(등록 허용 환경) | M1-01 |
| [M1-03](../tickets/M1-03.md) 강사 로그인 | 강사 탭 입력과 '입장하기' 버튼 스샷 | M1-01, M0-03 |
| [M1-04](../tickets/M1-04.md) 수업 생성 | 수업 이름·방 개수 입력, '수업 만들기' 버튼 스샷 | M1-03 |
| [M1-05](../tickets/M1-05.md) 공통 초대 코드 | 수업 카드의 공통 수업 코드·'코드 복사' 확대 | M1-04 |
| [M1-06](../tickets/M1-06.md) 신규 입장 개방·차단 | '새 학생 입장 닫기'·'열기' 양 상태 스샷, 촬영 후 열림 상태 복구 | M1-05 |
| [M1-07](../tickets/M1-07.md) 학생 ID 일괄 발급 | '학생 N명 발급' 결과와 '발급 ID 내려받기'(CSV) 스샷 | M1-04 |
| [M1-08](../tickets/M1-08.md) 학생 수업 코드 입력 | 학생 탭 수업 초대 코드 입력·'자리 선택하기' 스샷 | M1-01, M0-04 |
| [M1-09](../tickets/M1-09.md) 조·자리 선택 로비 | 조별 학생 1~5 자리 버튼, 사용 중·빈 자리 구분 스샷 | M1-08, M0-05 |
| [M1-10](../tickets/M1-10.md) 발급 ID 입장 | 방 코드·발급 ID 입장 화면 스샷(기존 방식) | M1-07 |
| [M1-11](../tickets/M1-11.md) 편집실 입장 상태 | 입장 직후 편집 화면과 '서버 연결됨' 확대 | M1-09 |
| [M1-12](../tickets/M1-12.md) 내 자리 복귀 | 같은 브라우저 재입장 시 '내 자리로 돌아가기' 스샷 | M1-11 |

태스크 완료 게이트: 모든 티켓 `done` + 산출물을 실제 화면으로 다시 열어 확인.
