# M7 — 강사 기능

상위: [MAN-001](../PLAN.md)

**목표:** 수업 운영·관찰·개입·복원 기능 촬영

| 티켓 | 결과 | 선행 |
|---|---|---|
| [M7-01](../tickets/M7-01.md) 조별 배치 미리보기 | 대시보드 방 배치 미리보기에 학생 배치 반영 | M3-01 |
| [M7-02](../tickets/M7-02.md) 생성 한도 표시 | 현재 테스트 모드 '생성 횟수 제한 없음' 안내 스샷, 제한 환경 입력칸은 코드 근거로 설명 | M7-01 |
| [M7-03](../tickets/M7-03.md) 학생 접속 현황 | '1조 학생 관리' 학생 1~5 접속 상태·빈 자리 스샷 | M7-01 |
| [M7-04](../tickets/M7-04.md) 접속 종료 | '접속 종료' 버튼 안내 스샷(클릭 즉시 실행이므로 촬영 후 재입장 확인) | M7-03 |
| [M7-05](../tickets/M7-05.md) 학생 삭제·자리 비우기 확인 | '학생 삭제' 확인창(물건 함께 삭제 선택) 스샷, '삭제하지 않기'로 취소 | M7-03 |
| [M7-06](../tickets/M7-06.md) AI 대화 열람 | '학생 대화 로그 열기' → 학생 선택 → 대화 목록 | M4-04 |
| [M7-07](../tickets/M7-07.md) 대화 상세·이전 기록 | '호출 명령과 원본 응답' 펼침, '이전 대화 더 보기' 스샷 | M7-06 |
| [M7-08](../tickets/M7-08.md) 강사 편집 참여 | 조 카드 → 편집실 입장, '강사 대시보드' 링크 스샷 | M7-01 |
| [M7-09](../tickets/M7-09.md) 에셋 개별 복원 | 선택 에셋 이력 → '이 에셋 복원' 전후, '이전 이력 더 보기' 표시 | M7-08 |
| [M7-10](../tickets/M7-10.md) 방 시점 복원 | 방 이력 → '이 시점의 방 복원' 전후 | M7-09 |

태스크 완료 게이트: 모든 티켓 `done` + 산출물을 실제 화면으로 다시 열어 확인.
