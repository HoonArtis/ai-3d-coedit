## 절차

1. 선행 산출물을 확인한다. 2. 촬영/제작한다. 3. 결과 파일을 직접 열어 눈으로 확인한다(빨간 표시 위치·글자 가독성·영상 재생).
4. 틀리면 고쳐 같은 조건으로 다시 확인한다. 같은 문제 2회 실패 시 원인 조사 후 기록. 5. 산출물 경로와 확인 결과를 아래에 적고 `done`.
