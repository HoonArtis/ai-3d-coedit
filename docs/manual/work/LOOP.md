# 설명서 루프 실행 규칙

한 번의 루프 = 티켓 하나.

1. `py docs/manual/work/check.py` 로 진행률과 **다음 실행 가능** 티켓을 본다. `doing`이 있으면 그것부터 이어 한다.
2. 고른 티켓 파일의 상태를 `doing`으로 바꾼다.
3. 서버가 꺼져 있으면 M0-01 절차로 다시 켠다(웹 4173, 방 서버 2567, `npm run dev:llm`, `npm run dev:cpu`, Ollama `OLLAMA_MODELS=D:/AI/ollama_models`).
4. `docs/manual/capture/`의 스크립트로 촬영·주석·영상을 만든다. 산출물은 `docs/manual/media/<티켓ID>-*.png|mp4`.
5. 결과 파일을 **직접 열어서** 확인한다. 빨간 표시가 맞는 자리에 있는지, 확대본 글자가 읽히는지, 영상이 재생되고 동기화가 보이는지.
6. 통과하면 티켓의 `## 실행 기록`에 산출물 경로·확인 내용을 적고 `done`. 막히면 `blocked` + 해제 조건을 적고 다른 실행 가능 티켓으로 넘어간다.
7. 태스크의 마지막 티켓이 끝나면 태스크 게이트(산출물 전체 재확인)를 수행한다.
8. M7-02 이후에는 `guide.html`을 다시 조립하고, M7-03에서 Artifact로 발행·재발행한다.

종료 조건: `check.py`가 `N/N done`이고 발행 링크에서 이미지·영상이 모두 보일 때.

금지: 찍지 않은 화면을 그려 넣기, 기존 수업/계정/작품 수정·삭제, GPU·헤드셋 대체 사실 숨기기.
