# 기능 설명서 제작 플랜 — MAN-001

**목표:** 서버를 켜고 강사·학생 2명이 실제로 쓰는 현장을 촬영해, 기능별(메인·챗봇·AI 생성·강사·VR)로 스샷 + 확대 + 빨간 표시 + 짧은 영상으로 설명하는 단일 HTML 웹문서를 만든다.

**산출물:** `docs/manual/guide.html`(단일 문서) + `docs/manual/media/`(스샷·크롭·영상). 촬영 스크립트는 `docs/manual/capture/`.

**규칙:** 실제로 찍지 못한 화면은 만들어 넣지 않는다. GPU·헤드셋처럼 대체한 부분은 문서에 대체 사실을 적는다. 기본 데이터(기존 수업·계정)는 건드리지 않고 설명서 전용 강사 계정만 쓴다.

**문체:** 제목은 명사형 개조식(예: 원형 배치, 최근 AI 작업 취소). 본문은 문어체 개조식, 구어체 어미 금지. UI 문구·요청 예문은 원문 그대로 인용. 완료 판정은 3종으로 구분: [촬영] 실제 화면, [코드 근거] 실화면 불가 시 코드·문서 근거 설명(대체 사실 표기), [미발생] 실제 사례 없음 표기. 셋 다 실행 기록에 종류 명시.

**시연 상태 계약:** 모든 촬영은 설명서 전용 수업(capture/out/state.json의 classId·code)의 1조를 사용. 학생 1·2는 M0-05의 저장 자리. 각 티켓은 촬영 전 '준비' 상태를 만들고(필요 시 clearMine으로 자기 에셋 비움), 종료 상태·산출물을 실행 기록에 남김. 각 티켓 실행 기록에 대상 classId·roomId·actor, 학생 1·2 초기 에셋 수, 선택·이력 전제, 종료 상태를 기재. 좌석을 소모하는 발급 시연은 별도 수업 '발급 ID 시연' 사용(촬영 전 기존 발급 학생 remove).

**단일 HTML 기준:** 최종 guide.html은 이미지·영상·스타일을 base64로 내장한 단일 파일. 파일 하나만 다른 폴더로 옮겨도 표시·재생되어야 함. 크기 16MB 이하.

**검토 모델:** codex exec 기본 모델(2026-10-15 기준 gpt-6-astra, gpt-5.5는 계정에서 거부). 실제 모델명은 실행 기록에 기재.
