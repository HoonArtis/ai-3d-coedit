# 역할: 에디터 프론트엔드

맡는 것: 학생 에디터 화면 전체(3D 뷰포트, 기즈모, 카메라, 라이브러리, 속성 패널, 챗봇 패널 껍데기, 생성 진행 표시). 화면 시안은 `index.html` 3장.

## 할 일

1. **1인 에디터 (1일차)**: R3F 씬, 바닥 그리드, 라이브러리에서 드래그 앤 드롭 배치, TransformControls(이동 W·회전 E·크기 R), OrbitControls(휠 줌, 우클릭 궤도, 휠클릭 이동), 속성 패널 숫자 입력.
   - 완료: 1인으로 에셋을 놓고 세 가지 변형과 줌·궤도가 모두 되며, 숫자 입력과 기즈모 값이 서로 일치한다.
2. **명령으로 전환 (2일차, room-server와 함께)**: 모든 변형을 직접 씬에 쓰지 않고 `command-api.md`의 명령으로 보낸다. 화면은 서버 방송을 받아 갱신한다.
   - 완료: 브라우저 5개에서 같은 방을 열었을 때 어느 창의 조작이든 나머지 4개에 반영된다.
3. **잠금 표시**: 선택하면 lock 요청, 남이 잡은 에셋은 그 사람 색 테두리(이름표 없음). 거부되면 선택이 풀리고 짧은 안내.
   - 완료: 남이 잡은 에셋은 선택되지 않고, 강제 해제를 받으면 진행 중이던 드래그가 즉시 취소된다.
4. **되돌리기 UI**: Ctrl+Z/Y와 상단 버튼. 서버가 거부하면 "선생님이 수정한 에셋" 안내.
5. **챗봇 패널 (3일차, chatbot과 함께)**: 대화, 실행한 명령 요약, [방금 거 취소], LLM 대기 순번 표시.
6. **생성 UI (5일차)**: 이미지 미리보기 → [만들기]/[다시 그리기], 단계 진행 표시(이미지 → 형상 → 텍스처 → 감량), 남은 생성 횟수.

## 경계

- 카메라는 개인 상태다. 서버로 보내지 않는다.
- 드래그 중에는 위치만 실시간 송신하고, 놓는 순간 명령 1건을 확정한다.
- 복원 방송을 받으면 사라진 에셋에 걸린 선택·포커스를 해제한다(예상 버그 #12).
- 성능 기준과 상한은 `../budgets.md`를 따른다.
