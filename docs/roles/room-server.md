# 역할: 방 서버 (Colyseus)

맡는 것: 방 생성·입장·정원, 명령 판정(권한 → 잠금 → seq), 방송, 명령 이력, 개인 되돌리기, 자동 저장·스냅샷, 에셋 변경 이력과 복원. 명령 형식은 `../command-api.md`가 원본.

## 할 일

1. **방과 정원 (2일차)**: 수업 → 방 여러 개. 방당 학생 5인(강사 정원 외, VR 감상자 포함). 재접속 토큰으로 이어하기.
2. **판정 파이프라인**: 권한 검사 → 잠금 확인 → seq 부여 → 방송 + 이력 + 로그. 잠금 없는 쓰기는 무조건 거부.
   - 완료: 학생 B가 A의 에셋에 보낸 명령이 서버에서 거부되고 상태는 변하지 않는다.
3. **잠금**: 선택 시 lockOwner 설정, 해제 시 비움. 연결 끊김·하트비트 타임아웃이면 자동 해제. 강사 force_unlock.
4. **트랜잭션**: requestId 단위로 ops를 묶어 원자 적용. 챗봇 요청은 시작 시 대상 전체 잠금을 확보한다.
5. **개인 되돌리기**: 사용자별 스택. 대상 에셋의 마지막 변경자가 본인일 때만 허용.
6. **저장**: 명령 이력을 PostgreSQL에 계속 기록. 수업 종료 시 제출 스냅샷, 다음 수업에서 이어하기.
   - 완료: 서버를 재시작해도 방이 마지막 seq 상태로 복구된다.
7. **이력·복원 (7일차)**: 에셋별 변경 이력, 강사의 에셋 복원·스냅샷 복원, 학생 알림(요청 단위로 묶음).

## 예상 버그 12건 (7일차에 전부 점검)

| # | 상황 | 대응 규칙 |
|---|---|---|
| 1 | 학생 드래그 중 강사가 강제 해제 후 수정 | 드래그 즉시 취소 + 잠금 없는 쓰기 거부 |
| 2 | 강사가 고친 에셋에 학생이 Ctrl+Z | 마지막 변경자가 본인일 때만 허용, 아니면 거부 + 안내 |
| 3 | 복원 후 학생 redo 스택에 옛 기록 | 복원 시 해당 에셋 관련 undo/redo 무효화 |
| 4 | 스냅샷 복원 중 생성 작업 완료 | 결과를 "방 + 스냅샷 세대 번호"로 검증, 다르면 라이브러리에만 |
| 5 | 복원 시 방 상한 초과 | 복원도 상한 검사, 실패를 강사에게 명시 |
| 6 | 챗봇 다단계 작업 중 강사 수정 | 트랜잭션 시작 시 전체 잠금, 실패 시 전체 롤백 |
| 7 | 강사 일괄 수정으로 알림 폭주 | 요청 단위 묶음 알림 |
| 8 | 드래그 중 매 프레임 기록 | 드래그 종료 시 1건만 |
| 9 | 잠금을 쥔 채 연결 끊김 | 끊김 감지·하트비트 타임아웃으로 해제 |
| 10 | 클라이언트 시계로 정렬 | 서버 seq만 신뢰 |
| 11 | 강사가 학생 에셋 복제 | 수정은 소유권 유지, 복제본은 복제한 사람 소유 |
| 12 | 복원 후 사라진 에셋을 선택 중 | 클라이언트가 복원 방송 수신 시 선택·포커스 해제 |

## 경계
