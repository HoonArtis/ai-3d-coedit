# 역할: 웹VR 감상

맡는 것: 헤드셋 브라우저용 감상 클라이언트, VR 굽기 규칙, 조원 아바타, 기기 검증.

## 범위

제출 스냅샷을 읽기 전용으로 감상한다. 조원은 아바타로 함께 보고, 이동은 텔레포트만 한다. 헤드셋 4대를 조별로 쓴다. 편집 중인 방에 실시간 접속하는 기능은 보류.

## 할 일

1. **진입 (6일차)**: 2D 진입 화면에서 조 스냅샷 선택 → [VR 입장] 버튼. `@react-three/xr` 6.6.31.
   - **HTTPS 필수**(localhost만 예외). PICO 4 Ultra는 HTTP 불가, Quest는 HTTP면 브라우저 플래그 수동 설정이 필요하다.
   - `requestSession('immersive-vr')`은 버튼 클릭 같은 사용자 조작 안에서만 호출된다.
2. **VR 굽기 규칙**: 에셋별 VR LOD(약 2,500 삼각형), 텍스처 아틀라스, 정적 병합, KTX2 1024. 수치는 `../budgets.md`.
   - 완료: 상한(200개)이 찬 방을 Quest 2에서 열어도 72fps를 유지한다.
3. **아바타**: 학생이 업로드한 리깅 캐릭터. 1차는 전신 IK 없이 헤드셋 위치 추종 + 머리 회전, 손은 컨트롤러·손 모델로 따로. 캐릭터가 없으면 기본 머리+손. 위치는 Colyseus 감상 방으로 동기화.
   - 완료: 퀘스트에서 HTTPS 링크로 2인 이상이 같은 스냅샷에 들어가 서로의 아바타를 본다.
4. **기기 검증**: 사내 PICO 4 Ultra Enterprise **중국 내수판**의 WebXR 지원은 미확인이다. HTTPS 테스트 페이지로 1회 확인하고 결과를 `../../CLAUDE.md`의 미확인 목록에 반영한다.

## 참고

- Quest 손 추적은 WebXR 공식 지원, 사용자 동의 필요, 양손 핀치는 시스템 예약.
- 기기 지원: Quest 2/3/3S 지원, PICO 4 Ultra 지원(Pico OS 15.4.4U+), 구형 PICO 4는 미확인.
