# ROOM-02 — 방 입장과 순서 있는 명령 방송 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T03](../tasks/T03.md)
- 원본: [docs/roles/room-server.md](../../../docs/roles/room-server.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

수업·방을 분리하고 세션 actor를 검증한다. 같은 requestId 재전송은 중복 적용하지 않는다. 서버 seq만 순서로 쓰며 학생·VR 합계 5인과 강사 정원 외를 보장한다. 인증 fixture는 테스트에서만 사용한다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
