# CORE-02 — 순수 명령 처리 도메인 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T01](../tasks/T01.md)
- 원본: [docs/command-api.md](../../../docs/command-api.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

이동·회전·크기·배치·복제·삭제·이름 변경을 immutable 상태에 적용한다. CommandContext는 인증 주체·역할·허용 라이브러리·잠금 정보를 담으며 계약 모듈에 정의한다. 조회는 상태를 바꾸지 않는다. 실패한 여러 op는 이전 상태 그대로이며 복제본 소유자는 복제한 사람이다. DB·React·Colyseus import가 없다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
