# PERF-02 — 저사양 PC와 VR 성능 실측 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T08](../tasks/T08.md)
- 원본: [docs/budgets.md](../../../docs/budgets.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

내장 그래픽 편집 30fps와 Quest 2 감상 72fps를 실제 측정한다. 텍스처 1024 KTX2, VR draw call 150 이하, 최대 아바타 5인 조건을 기록한다. 기기·해상도·측정 구간·프레임 분포를 남기고 실패 시 최적화 티켓으로 연결한다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
