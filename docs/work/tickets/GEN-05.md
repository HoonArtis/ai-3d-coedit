# GEN-05 — 데스크톱 감량·저장·승인 대기 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T05](../tasks/T05.md)
- 원본: [docs/roles/generation-gpu.md](../../../docs/roles/generation-gpu.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

약 5천 삼각형·1024 KTX2·GLB로 변환하고 메타데이터/원본을 저장한다. 텍스처가 없으면 명시된 기본 재질을 사용하고 GEN-04 연결 시 같은 계약을 쓴다. 세대가 달라진 결과는 라이브러리 승인 대기로만 보내며 방에는 자동 배치하지 않는다. 미승인 결과는 공유하지 않는다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
