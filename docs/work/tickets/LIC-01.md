# LIC-01 — 웹·서버·테스트 의존물 도입 기준 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T09](../tasks/T09.md)
- 원본: [docs/licenses.md](../../../docs/licenses.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

React/R3F/three.js, 서버 후보, PostgreSQL client, BullMQ/Redis, TypeScript/Vite/Vitest/Playwright 및 모듈 검사 도구의 실제 도입 버전을 확인한다. 라이선스 불명 상태를 가능으로 바꾸지 않는다. 선정한 버전은 CORE-01에서 lockfile로 고정한다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
