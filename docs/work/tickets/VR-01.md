# VR-01 — VR 굽기 큐와 스냅샷 산출물 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T07](../tasks/T07.md)
- 원본: [docs/roles/webxr.md](../../../docs/roles/webxr.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

제출 스냅샷을 읽고 에셋당 약 2500 삼각형·전체 50만 이하·1024 KTX2·아틀라스·정적 병합으로 변환한다. draw call 150 이하를 실제 뷰어에서 확인할 산출물을 만든다. 원래 편집 씬은 바꾸지 않는다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
