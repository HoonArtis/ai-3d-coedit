# AI-02 — 도구 계약·MD 시스템 프롬프트·모델 평가 (분할 이력)

- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T04](../tasks/T04.md)
- 원본: [docs/roles/chatbot.md](../../../docs/roles/chatbot.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

역할·예시·씬 해석·모호성·권한의 다섯 프롬프트 영역을 작성한다. 로컬 우선 대표 한국어 요청 20개의 도구·인자 성공률과 지연을 기록해 선정한다. 문서의 클라우드 모델 ID도 실제 제공 여부를 확인한다. 프롬프트가 권한 판정을 대체하지 않는다.

## 묶음 확인

모든 자식 티켓의 증거를 확인하고 원래 완료 조건 누락 여부를 상위 태스크에서 검토한다. 자식 테스트 통과만으로 여러 모듈의 실제 통합을 생략하지 않는다. 검증 실패는 해당 자식 티켓에서 수정·재검증하고 2회 연속 실패하면 사례 조사를 수행한다.
