- 종류: 분할된 작업 묶음 — 실행 티켓 아님
- 상태: `split`
- 상위 태스크: [T09](../tasks/T09.md)
- 원본: [docs/licenses.md](../../../docs/licenses.md), [CLAUDE.md](../../../CLAUDE.md)

기존 큰 티켓을 아래 실행 티켓으로 대체했다. 이 문서는 원래 범위와 링크를 보존하며 진행률의 분모에 포함하지 않는다. 선행 작업은 자식 실행 티켓의 `선행 티켓` 필드가 원본이다.

## 원래 완료 조건

문서에서 판매 차단으로 지정한 RMBG-1.4·nvdiffrast를 대체하거나 계약 근거를 확보한다. 텍스처 대안이 없으면 재질 프리셋을 판매판 기본으로 설정한다. 테스트용 제한 의존물이 판매 산출물에 포함되지 않는지 검증한다.
