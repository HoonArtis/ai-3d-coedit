# 기본 블록 캐릭터 — 2026-10-14

사용자 요청: 업로드 없이 마인크래프트처럼 간단한 블록 캐릭터를 만들어 사용한다. 기존 게임의 스킨·파일을 복제하지 않고 상자 기하로 만든 기본 인물을 제공한다.

## 사용

편집 왼쪽 최상단 또는 VR 감상 화면의 **내 캐릭터** → 프리셋/색 선택 → **내 캐릭터 적용**. 3D 미리보기를 회전해 볼 수 있다. 현재 학생 자리의 서버 프로필로 저장되며 같은 자리로 재로그인하면 복원된다. 명시적인 블록 선택은 업로드 캐릭터보다 우선한다. 기존 업로드 캐릭터 사용 버튼은 선택을 해제한다. 업로드가 없으면 기본 블록 인물로 표시한다.

VR 감상 연결 중 변경은 서버가 저장된 본인 프로필을 다시 읽어 전파한다. 임의 actor나 프로필을 WebSocket 메시지로 전달하지 않는다. 재접속으로 방 정원을 순간적으로 초과하지 않는다. VR 세션 안에서는 편집 버튼을 비활성화한다.

## 검증·수정·재검증

- 신규 통합 테스트를 먼저 실행해 미구현 서비스 실패 확인.
- 첫 마이그레이션에서 기존 room ID가 text인 점을 반영해 FK 타입 수정; 재실행 통과.
- 통합: 다른 자리 설정 분리, 재로그인 복원, 타 조 거부, 위조 actor·잘못된 색 거부, 선택 해제.
- 브라우저: 업로드 없이 선택/저장, 새로고침 복원, VR 화면 설정, 실제 Colyseus 프로필 전송, 연결 중 색 변경·해제 통과. 초기 해제 테스트의 Content-Type 누락을 수정해 실제 JSON null 요청으로 재검증.
- 기존 업로드 캐릭터 변환/배치/VR 및 VR 권한/미지원 브라우저 테스트 3개 통과.
- 전체 단위/통합 테스트 기본 병렬 실행에서 기존 accounts migration deadlock 1건. 순차 `npx vitest run --maxWorkers=1` 75파일 236테스트 통과. 병렬 DB 마이그레이션 경합은 별도 검증 환경 문제로 기록한다.
- 빌드/타입, 모듈 경계, 작업 장부 검사 통과. 독립 코드 리뷰에서 중요 결함 없음. 리뷰 후 재접속 대신 프로필 갱신 메시지로 전환하고 브라우저 테스트 추가.
- 실제 UI 스크린샷 `block-avatar-picker.png` 확인: 전신 블록 인물, 프리셋·색 선택·적용 상태가 표시됨.
- 배포 후 외부 HTTPS 링크에서 본인 프로필 조회·프리셋 변경 미리보기 성공. 사용자 장면·프로필은 변경하지 않고 확인했다.

## 모듈화 검증과 한계

공통 계약은 색/프로필/전송 형식만 정의한다. AvatarProfileService가 인증·저장을 담당하고 ViewingRoom은 인증된 actor의 프로필을 전송한다. AvatarPicker는 UI/API, BlockCharacter는 재사용 가능한 기하 렌더만 담당한다. 기존 업로드/생성/GPU를 호출하지 않는다.

머리 위치/회전 추종과 별도 손 표시만 지원한다. 전신 IK·보행 애니메이션·맵 에셋 배치는 포함되지 않는다. 낮은 헤드셋 높이에서는 고정 1.6m 신체 기준 때문에 다리가 바닥 아래로 내려갈 수 있다. Quest 3 실기기 동작·성능은 아직 미검증이다.
