# 외부 터널 시험 — 2026-10-14

실행 범위: 임시 공개 HTTPS 링크, 인증 서버, 실제 두 브라우저 WSS 연결과 AI 편집. 별도 외부 기기·5/15/30명 시험은 아직 하지 않았다.

## 구성과 결과

- 인증 서버는 loopback 2570에서 dist/web과 API/Colyseus를 함께 제공한다. Cloudflare Quick Tunnel만 이 진입점에 연결한다.
- 기존 자료와 분리한 새 PostgreSQL schema에 무작위 강사 자격정보와 학생 5명을 발급했다. 개인 접속 정보는 .secrets 및 바탕화면 개인 파일에만 있으며 Git에 넣지 않는다.
- 공개 강사 가입 403, 익명 local-session 404, .env 404. 로그인 없는 첫 화면은 학생 로그인이다.
- 서버 주소는 server-endpoint.ts로 공통화했다. 개발은 로컬 backend, production은 페이지 origin을 따른다. 브라우저 localhost 요청 0건.
- 실제 Cloudflare HTTPS를 통과한 두 Chromium context: 로그인, WSS, 테이블 배치 동기화, 실제 Qwen3:4b 의자 4개 배치, 되돌리기, 새로고침 복구 통과. 페이지 오류 0건. 원값 external-access.json.
- 새 테스트 2건: 구현 전 static root 404/endpoint module 누락 RED → 구현 후 GREEN. 타입 import 문법과 Application 타입 불일치는 원인 확인 후 수정했다.
- 신규/회귀 단위·통합 200개 통과. 빌드·모듈 검사 통과. 브라우저 전체 결과는 아래 실행 기록을 따른다.
- 코드 리뷰: 이번 변경에서 Critical/Important 없음. 기존 proxy-IP 로그인 제한과 만료 토큰 재로그인 UX는 임시 2인 시험을 막지 않으므로 이번 변경에서 유지한다. 대규모 접속 시 별도 검증한다.

## 검증 한계와 후속

외부망의 다른 PC/휴대전화는 아직 미검증이다. 사용자에게 모바일 데이터에서 직접 확인을 요청한다. 사용자 수 상한과 VR 실기기 성능을 추정하지 않는다. 이번 공개 검증에서 3D 생성 전체를 새로 수행하지는 않았다. GPU/CPU 워커 및 기존 모델·컨테이너는 기동·존재 확인했다.

Quick Tunnel은 임시 테스트용이며 종료하면 링크가 만료된다. 자동 시작 서비스로 설치하지 않았다. 최상위 START_HERE.md와 docs/operations/external-access-plan.md를 따른다.

공식 안내: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

## 공통 코드 클래스룸 추가

사용자 선택에 따라 개인 링크 대신 공통 수업 코드/학생 자리 로비를 구현했다. 별도 ClassInvites 서비스·라우터·공통 계약, ClassInvite/ClassLobby UI로 책임을 분리했다. 수업 행 잠금과 기존 학생 고유 제약으로 중복 자리 선택과 기존 발급 ID 충돌을 막는다. 사용한 자리는 세션 종료로 풀지 않으며 브라우저 복귀 키의 해시로 같은 학생으로 재입장한다.

실제 공개 HTTPS 브라우저 결과(classroom-invites.json): 강사 로그인/수업2방 생성/코드 발급, 학생2명 로비 입장/중복 자리 비활성, 공동 편집, 같은 브라우저 복귀, 강사 편집실 입장 PASS. 독립 외부 기기는 미검증이다.

새 코드 리뷰에서 로비 polling과 입장 제한을 공유하는 결함을 재현했다(125회 조회 후 claim429). 조회600/min와 입장120/min 예산을 분리한 뒤 같은 시험 PASS. 복귀 키81자 입력이 자리를 차지한 뒤 로그인에 실패하는 경계도 재현하고, 기존 로그인 최대80자와 일치시켜 삽입 전 거부하도록 수정했다. UI 키는32바이트 무작위 값이다. 인증 테이블 최초 동시 migration 경합은 schema별 advisory transaction lock으로 직렬화했다.

단위·통합 최종203개 PASS, 전체 브라우저29개 PASS. 강사가 공개 루트로 재방문할 때 클래스룸 목록을 표시하는 추가 회귀 사례도 별도로 RED→GREEN 통과했다. 변경 후 공개 HTTPS에서 강사 재방문과 공통 코드/2인 입장 흐름을 다시 실행해 통과했다. 기존 131개 티켓의 완료 기록과 이번 후속 구현을 혼동하지 않는다.

현재 제한: 브라우저 저장소 삭제나 다른 기기에서 기존 자리 복구/교사 자리 회수는 미지원이다. 학생은 코드를 아는 사람이 빈 자리를 선택하는 방식이며 실명 인증이 아니다. 그룹 규모 실측과 독립 모바일 데이터 접속 결과는 별도 확인한다.
