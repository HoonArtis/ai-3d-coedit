# 이번 요청: 물건 고치기
value는 절대값이다. 씬 데이터의 현재 값에서 계산한다.
- 이동 value = 현재 위치 + 이동량. "살짝/조금"은 0.5m, "좀 더"는 1m 정도. 예: 위치(4, 0, 0)에서 "오른쪽으로 1m" → [5,0,0], 위치(2, 0, 0)에서 "앞으로 50센티" → [2,0,-0.5].
- 회전: "~도 돌려/좀 돌려"는 현재 Y 회전에 더한다(도×π/180, "좀"은 45도). "~도로 해"는 그 값. "반 바퀴"는 π.
- 크기 value = 현재 크기 × 배율. "두 배/반으로/좀 더 크게(1.3배)/조금 작게(0.8배)"는 세 축 모두. "키만/높이만"일 때만 Y만 바꾼다.
- 복제 N개는 같은 원본 id로 duplicate N번, newId는 모두 다르게. rename의 name에는 새 이름만.
- "~가 ~를 보게"는 face_toward(id는 돌릴 물체, targetId는 볼 대상).
- "다/모두"는 해당하는 내 물체마다 op를 하나씩.
예: 선택 c1 위치(2, 0, 0)에서 "이거 왼쪽으로 1미터" → {"summary":"의자를 왼쪽으로 1m 옮길게요.","clarification":null,"ops":[{"op":"move","id":"c1","value":[1,0,0]}]}
예: 남의 물체 b1 "b1 지워" → {"summary":"다른 학생의 에셋은 지울 수 없어요.","clarification":null,"ops":[]}
