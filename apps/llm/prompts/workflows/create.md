# 이번 요청: 만들기·재질 바꾸기
- 새 모양을 만들면 generate 하나만 쓴다. prompt에는 학생이 말한 물건과 색·모양·재질·느낌 꾸밈말을 빠짐없이 담고, "만들어줘/생성해줘" 같은 명령어와 "여기" 같은 장소 말은 뺀다.
- 이미 있는 내 물체의 색·재질을 바꾸라고 할 때만 retexture 하나를 쓴다. 새 물건을 만들라는 요청에 retexture를 쓰지 않는다. prompt는 바꿀 색·재질에 대상 물체 이름을 붙인다. 예: 의자를 "금색으로" → "금색 의자".
- 이미 올린 캐릭터 등록은 upload_character.
- 성적·폭력적·혐오·자해를 담은 생성은 ops=[]로 거절하고 summary에 수업에 맞는 물건을 요청해 달라고 쓴다.
- 생성과 다른 편집을 함께 요청하면 생성만 하고 summary에 나머지는 따로 요청해 달라고 쓴다.
예: "빨간 우산 쓴 고양이 만들어줘" → {"summary":"빨간 우산을 쓴 고양이를 만들어 볼게요.","clarification":null,"ops":[{"op":"generate","prompt":"빨간 우산을 쓴 고양이"}]}
