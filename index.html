1. 개요와 수업 흐름

  • 무엇: 언리얼 에디터의 배치·이동·회전·크기조절·카메라 조작을 웹(three.js + React Three Fiber)으로 재현한 3D 공간 꾸미기 프로그램. 언리얼 미사용.
  • 차별점: 학생마다 개인 AI 챗봇. MCP가 언리얼을 조작하듯 챗봇이 씬 명령을 직접 호출. "알아서 배치해" 수준까지.
  • 협업: 한 맵에 최대 5인 동시 접속, 각자 에셋을 놓으며 공동 꾸미기.
  • 에셋: 준비된 라이브러리 + 자체 클라우드 GPU의 AI 3D 생성(TripoSG).
  • 마무리: 완성한 공간을 퀘스트·피코 브라우저 웹VR로 조원과 함께 감상.
  • 대상·기기: 고등학생, 저사양 PC·노트북 브라우저(마우스). 강사 구매 → 학생 초대(판매 모델은 보류).

명령 공통 규칙

  • 모든 명령은 {actor, source: "gizmo"|"chat"|"teacher", requestId, ops[]}. 서버가 순번(seq)을 매겨 방송.
  • 챗봇 요청 1회 = 트랜잭션 1개. 중간에 하나라도 실패하면 전체 롤백, 되돌리기도 1단위.
  • 드래그 중에는 위치만 실시간 방송(저장 안 함), 놓는 순간 1건 기록.
  • 방 에셋 상한 200개, 생성물은 약 5천 삼각형·텍스처 1024(KTX2)로 자동 감량. 상한 근접 시 챗봇이 안내.

5. 챗봇 설계

  • 형태: 화면 옆 패널, 학생마다 1개. 월드 안 아바타 없음. 그 학생의 권한을 그대로 따름.
  • MD 파일(시스템 프롬프트) 구성
    1. 역할과 말투: 고등학생 대상, 짧고 친절하게, 실행 전 무엇을 할지 한 줄 요약
    2. 도구 목록: 4장 명령표 그대로. 도구마다 언제 쓰는지 + 예시 문장 2~3개
    3. 씬 읽는 법: describe_scene 결과(이름·소유자·위치·크기) 해석 규칙
    4. 모호할 때: "저거", "여기"는 현재 선택·카메라 중심 기준. 그래도 모호하면 한 번만 되묻기
    5. 금지: 남의 에셋 수정, 부적절한 생성 요청(필터 목록), 상한 초과
  • 모델: 로컬 우선, 클라우드는 차선. 후보는 도구 호출을 지원하는 공개 모델(예: Qwen3 계열, gpt-oss-20b) 라이선스·품질 실측 필요. 차선 클라우드는 Claude Haiku 5.5(claude-haiku-5-5).
  • 큐: LLM 요청도 동시 처리 수 제한 큐를 거침(학생 30명 동시 요청 대비). 대기 시 "앞에 n명" 표시.
  • 로그: 대화 전문·호출한 명령·결과를 저장, 강사 열람.

6. 생성 파이프라인

  • 횟수 제한: 수업당 1인 N회(강사 설정). 대기열 순번과 진행 단계 표시.
  • 승인: 생성물은 강사 승인 후 공유 라이브러리에 공개. 부적절 생성물 거르기 겸용.
  • 차선책(기록만): 텍스처 생성 대신 미리 만든 재질 프리셋(나무·금속·천 등) 중 AI가 골라 입히기. 즉시 적용, GPU 비용 0, 대신 물체당 재질 1개.
  • 캐릭터: 맵 배치(대기 애니메이션 재생)와 VR 아바타 겸용.

7. 멀티플레이·이력·예상 버그

  • 잠금: 선택하는 순간 잠금, 잡은 사람 색 테두리. 놓을 때까지 다른 사람은 못 잡음. 연결이 끊기면 자동 해제(타임아웃). 강사는 강제 해제 가능.
  • 되돌리기: 개인 기준. 남이 한 작업은 내 Ctrl+Z로 사라지지 않음. 챗봇 요청 1회는 1단위.
  • 저장: 명령 이력을 계속 저장(자동 저장). 수업 종료 시 제출 스냅샷, 다음 수업에서 이어하기.
  • 강사 수정 이력: 에셋마다 누가·언제·무엇을 기록. 강사가 학생 에셋을 바꾸면 그 학생에게 알림. 에셋 단위 복원과 방 스냅샷 복원.

강사 수정·이력·복원에서 날 수 있는 버그

#상황증상대응 규칙
1학생이 드래그 중인 에셋을 강사가 강제 해제 후 수정학생이 손을 놓는 순간 낡은 위치로 덮어써 강사 수정이 사라짐강제 해제 시 학생 쪽 드래그 즉시 취소 + 서버가 잠금 없는 쓰기 거부
2강사가 고친 에셋에 학생이 Ctrl+Z학생 되돌리기가 강사 수정을 되돌리거나 중간 상태로 튐대상의 마지막 변경자가 본인일 때만 허용, 아니면 거부 + 안내
3강사가 복원했는데 학생 redo 스택에 옛 기록이 남음다시하기로 복원 전 상태가 부활복원 시 해당 에셋 관련 undo/redo 스택 무효화
4방 스냅샷 복원 중 생성 큐 작업이 완료됨복원된 방에 엉뚱한 생성물이 끼어듦생성 결과를 "방 + 스냅샷 세대 번호"로 검증, 다르면 라이브러리에만 넣음
5삭제된 에셋을 복원했는데 방 상한(200개)이 참상한 초과 또는 조용한 실패복원도 상한 검사, 실패 시 강사에게 명시적 오류
6챗봇 다단계 작업 도중 강사가 대상 하나를 수정일부만 적용된 어정쩡한 배치트랜잭션: 시작 시 대상 전체 잠금 확보, 실패 시 전체 롤백
7강사가 "전체 정렬" 같은 일괄 수정학생에게 알림 수십 개 폭주요청 단위로 묶음 알림("선생님이 에셋 12개를 정리했어요")
8드래그 중 매 프레임 이력 기록이력·DB 폭증드래그 종료 시 1건만 기록
9잠금을 쥔 채 브라우저가 끊김에셋이 영영 잠김연결 끊김 감지 시 해제 + 하트비트 타임아웃
10클라이언트 시계로 이력 정렬순서 뒤바뀜, 복원 대상 틀어짐서버 순번(seq)만 신뢰
11강사가 학생 에셋을 복제복제본 소유자 모호수정은 소유권 유지, 복제본은 복제한 사람 소유(강사가 이전 가능)
12복원 후 학생 화면이 사라진 에셋을 선택·주시 중속성 패널 오류, 카메라가 빈 곳을 봄복원 방송 수신 시 존재하지 않는 선택·포커스 해제

8. 웹VR과 성능 한계 수치

  • 범위: 기본은 제출 스냅샷을 읽기 전용으로 감상, 조원이 아바타로 함께 둘러봄. 헤드셋 4대 조별 사용. 편집 중인 방에 실시간 접속은 여유 시 확장.
  • 아바타: 업로드한 리깅 캐릭터. 1차는 전신 IK 없이 헤드셋 위치 추종 + 머리 회전, 손은 따로 표시. 캐릭터가 없으면 기본 머리+손.
  • 진입 조건: HTTPS 필수(localhost만 예외). Quest에서 HTTP는 브라우저 플래그 수동 설정 필요, PICO 4 Ultra는 HTTP 불가. requestSession('immersive-vr')은 버튼 클릭 같은 사용자 조작 안에서만.
  • 라이브러리: @react-three/xr 6.6.31(peer: react ≥18, @react-three/fiber ≥8). 컨트롤러·손 입력 지원. Quest 손 추적은 사용자 동의 필요, 양손 핀치는 시스템 예약.

10. 1주 일정과 자르는 순서

일차목표완료 기준
1에디터 핵심: 라이브러리 배치, 기즈모, 카메라(줌·궤도)1인으로 에셋 놓고 이동·회전·크기조절
2Colyseus 방, 5인 동기화, 잠금 테두리, 개인 되돌리기, 저장브라우저 5개에서 같은 방 편집, 새로고침 후 복구
3명령 API에 챗봇 연결, 자동 배치 도구, 로컬 LLM, MD 파일"탁자 주위에 의자 4개"가 한 번에 실행·되돌리기 1단위
4강사 계정 일괄 발급, 방 코드 입장, 대화 로그 / 작업 큐 골격강사가 6개 방 생성, 학생 ID로 입장
5생성 파이프라인: 이미지 모델 → 확인 → TripoSG → 텍스처 → 감량글 한 줄로 텍스처 입힌 GLB가 방에 배치
6웹VR 감상: 스냅샷, VR 굽기, 조원 아바타, 텔레포트퀘스트에서 HTTPS 링크로 입장, 2인 이상 함께 감상
7강사 이력·복원, 캐릭터 업로드, 통합 테스트예상 버그 1~12 점검

11. 위험 항목

#위험영향대응
1비상업 의존물: RMBG-1.4(배경 제거), nvdiffrast(텍스처 렌더링)그대로면 판매 불가테스트는 그대로 사용. 판매 전 필수 과제로 교체(배경 제거는 상업 가능 모델로, nvdiffrast는 대체 경로 또는 NVIDIA 계약). 끝내 안 되면 재질 프리셋 차선책이 판매판 기본
2생성 시간 미실측(추정 1~3분)수업 중 대기 체감, 30명 동시 시 큐 적체5일차 실측. 학생 확인 단계로 헛생성 차단, 횟수 제한
3로컬 LLM 도구 호출 품질엉뚱한 도구·인자, 한국어 이해 부족좌표 계산은 코드로, MD 파일에 예시 집중. 실패율 높으면 클라우드 차선
4GPU 1장에 LLM + 생성 동시VRAM 부족, 응답 지연LLM 상주 + 생성 동시 1개. 부족하면 LLM 경량화 또는 GPU 분리
5VR 성능(Quest 2)프레임 저하, 멀미8장 예산 준수, VR 굽기 단계
6사내 PICO 중국 내수판 브라우저 WebXR 미검증사내 시연 기기로 못 씀실기기로 HTTPS 테스트 페이지 1회 확인
7학생 업로드 캐릭터 품질 편차VR 프레임 저하, 깨진 아바타업로드 시 감량·검사, 실패 시 기본 아바타
8미성년자 대상 생성물·대화부적절 콘텐츠프롬프트 필터, 강사 승인, 대화 로그
